# 💎 Powar Jewellers Website

A modern, responsive jewellery website developed using **HTML, CSS, and JavaScript**. The website showcases elegant jewellery collections with a premium user interface and a seamless browsing experience across desktop and mobile devices.

## ✨ Features

* Responsive design for all screen sizes
* Luxury-themed user interface
* Gold Jewellery Collection
* Silver Jewellery Collection
* Earrings Collection
* Product cards with images, product codes, and net weight
* Smooth navigation and hover effects
* WhatsApp inquiry integration
* Mobile-friendly navigation menu
* Clean and organized project structure

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
